# 🎬 IMDb Movie Box Office Analysis Dashboard – Power BI

## 📌 Project Overview
The IMDb Movie Box Office Analysis Dashboard is a data visualization project developed using Microsoft Power BI. The main objective of this project is to analyze movie industry performance based on revenue, ratings, genres, actors, directors, and profitability.

This dashboard helps users understand movie trends, identify successful movies, compare genre performance, and analyze the relationship between movie ratings and box office revenue.

## 🎯 Project Objectives
- Analyze overall movie performance.
- Identify the highest-rated and most successful movies.
- Compare revenue across different movie genres.
- Analyze actor and director performance.
- Understand yearly movie trends.
- Classify movies into Hit, Average, and Flop categories.
- Monitor movie profitability and financial performance.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated columns and measures.
- **Excel / CSV** – Dataset management.
